# PDA Platformer

Overview
- A small 2D platformer built with Godot (tested with Godot 4.x). This repository contains scenes, GDScript game logic, and a minimal test runner for unit tests.

Project structure
- `project.godot` — project configuration and autoloads.
- `scripts/` — game logic scripts (GDScript). A helper module `scripts/game_logic.gd` contains pure functions used by multiple scripts.
- `rooms/` — level scenes and shared audio player scene.
- `some bs/` — autoload services (e.g. `SoundManager.gd`, `speedrun.gd`, `Global.gd`).
- `tests/` — test runner scene and script: `tests/test_runner.tscn` and `tests/test_runner.gd`.

What was refactored
- Extracted repeated pure logic into `scripts/game_logic.gd`: time formatting, building room scene paths, jump calculations, `is_player_body`/`is_enemy_body` checks, and similar helpers.
- Updated several trigger scripts to use the helper functions to reduce duplication.
- Added a simple Godot test runner (`tests/test_runner.tscn`) that runs unit tests for functions in `scripts/game_logic.gd`.

How to run tests (manual)
1. Open the project in Godot (4.x recommended).
2. Open the scene `tests/test_runner.tscn`.
3. Run the scene (Play Scene). The Output panel will show `PASS` or `FAIL` messages for each test.

Tested files and helpers
- Helper functions: [scripts/game_logic.gd](scripts/game_logic.gd#L1)
- Test runner: [tests/test_runner.gd](tests/test_runner.gd#L1) and [tests/test_runner.tscn](tests/test_runner.tscn)

Limitations
- Current tests cover only pure, easily testable functions (formatting, calculations, simple boolean checks). Most of the scene-specific logic (physics, input, animations, full scene transitions, file I/O) is not covered by automated tests yet.
- To run tests in CI, you will need a headless Godot or an exported test runner build.

Recommended next steps
